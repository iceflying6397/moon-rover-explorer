# Moon Rover Explorer · SELENE 月面漫游

一个完全在本地运行的三维月球探索网页。支持 SELENE 流线月球车、VIPER 月球极地探测车与白色机甲六轮巡视器，在同一个月面场景中随时切换。默认展示根据参考图制作的 SELENE。

## 首次运行

需要 Node.js 22.13+ 和支持 WebGL 2 的现代浏览器。首次下载并运行：

```sh
git clone https://github.com/iceflying6397/moon-rover-explorer.git
cd moon-rover-explorer
npm ci
npm run check
npm start
```

`npm run check` 会检查代码、模型和地形，并生成本地网页。首次安装依赖需要网络；网页生成后，模型、贴图、脚本、图标均在本地，正常浏览不依赖互联网。

## 再次打开网页

在 macOS 上双击 **启动月面漫游.command**。它会启动本地网页并打开浏览器，关闭终端或按 Ctrl+C 即可停止。

也可以在项目目录运行：

```sh
npm start
```

打开终端中显示的本地地址，默认是 http://127.0.0.1:3000/。若端口已被占用，会自动选择 3001–3010 中的可用端口。

请通过本地服务打开，不要直接用 file:// 打开 HTML。仓库不包含依赖安装目录或构建产物，首次下载后需先按上面的步骤安装和构建。

## 操作

| 操作 | 方法 |
| --- | --- |
| 切换月球车 | 左上方「月球车模型」选择 SELENE / VIPER / 白色机甲 |
| 旋转 | 鼠标左键拖动 / 单指拖动；聚焦画面后方向键 |
| 缩放 | 鼠标滚轮 / 双指捏合；聚焦画面后 ＋ / － |
| 平移 | 鼠标右键拖动 / 双指拖动 |
| 自由移动 | 选择「自由探索」，W / A / S / D，Q / E 升降 |
| 加快视角移动 | 按住 Shift |
| 暂停 / 继续行驶 | 空格键或左下播放按钮 |
| 重置视角 | R 或重置按钮 |

| 操作指南 | 右上角信息按钮，横屏也可用 |

## 场景

- SELENE：约 12.4 万三角面，白色流线车身、太阳能顶板、金属网状轮；网页文件约 1.76 MB。
- 白色机甲：依据已确认的设计图制作，平滑珍珠白装甲、青蓝灯线、展开太阳翼、六个独立金属网面轮；网页文件约 4.59 MB、21.7 万绘制三角面。
- 约 18 万三角面的 VIPER 工程模型，四个独立车轮、悬架、相机桅杆、仪器和太阳能板。
- PBR 金属、隔热层褶皱、太阳能电池纹理，实时阴影和反射。
- Poly Haven Moon 01 的 2K 扫描材质；三维起伏地形、陨石坑、980–1,960 块岩石（按画质）与星空。
- 探测车沿月面缓慢行驶，车轮旋转、悬架贴合地形，并留下轮迹。暂停且视角静止时停止动画循环和重复绘制；切到后台后不累计探索时间。
- 白色机甲网页模型按材质合并静态零件，绘制批次从 213 减至 28，六轮独立转动和表面细节保持不变。
- 模型切换保留探索时间、距离、暂停状态、速度和当前视角；按车型适配车轮转动、轮距与车辙，新模型加载失败时保留当前车。
- 跟随、自由探索、近距离三个视角，以及全屏和沉浸模式。
- 无重叠的连续地形网格；车辆、相机、岩石、轮迹均使用实际三角网高度。
- 自动画质按屏幕、触屏能力与 CPU 核心数选择；持续低帧率会降至流畅档。手动选择不自动降档。切换画质保留车型、行驶状态和视角。
- 流畅 / 标准 / 精细地形分别为 50,688 / 170,496 / 303,104 三角面。阴影按 10 / 15 / 20 Hz 更新，暂停时补刷最终阴影。
- 尊重系统减少动态效果偏好：默认暂停，镜头切换直接到位。
- 固定名称模型和贴图采用 ETag / Last-Modified 校验；带版本的脚本长期缓存，刷新仍能获取新文件。

这是视觉探索演示，提供依据参考图制作的 SELENE、白色机甲概念模型和 Project Chrono 的 VIPER 研究模型。地形、路线和遥测为程序模拟，不是实测月球地形或真实任务数据。

## 修改与构建

安装依赖后，启动开发预览：

```sh
npm run dev
```

修改后重新生成本地发布版：

```sh
npm run check
npm start
```

使用随仓库提供的 Project Chrono 工程数据重新生成 VIPER GLB：

```sh
npm run build:rover
```

## 主要文件

- `app/page.tsx`：中文探索界面与操作状态。
- `app/globals.css`：界面样式与响应式布局。
- `lib/rover-catalog.ts`：轻量车型清单，页面无需提前加载三维库。
- `lib/rover-models.ts`：坐标适配、车轮运动及模型切换缓存。
- `lib/lunar-world.ts`：三维场景生命周期、行驶和相机控制。
- `lib/lunar-terrain.ts`：连续地形网格及与画面一致的高度查询。
- `lib/lunar-environment.ts`：分块岩石、星空与程序材质。
- `lib/scene-settings.ts`：画质参数及自动选择。
- `assets-source/viper/`：原始工程模型、装配参考与许可。
- `public/assets/`：本地 GLB 与 PBR 贴图。
- `scripts/build-rover.mjs`：装配并导出模型。
- `scripts/serve.mjs` / `static-server.mjs`：仅监听本机的静态网页服务与缓存处理。

资源来源与授权见 `public/CREDITS.md`，Project Chrono 的许可已保留。

SELENE 与白色机甲的 Blender 原工程、设计参考图和本地研究素材不随本仓库发布；运行所需的三款 GLB 和全部贴图已包含在 `public/assets/`。第三方资源的独立许可均保留在仓库中。

## 模型切换检查

运行 `npm run test:rover` 检查三份实际 GLB 的朝向、轮轴、接地和转动，以及手机取景、快捷键、快速选择、加载失败、缓存与卸载后的异步回调。
